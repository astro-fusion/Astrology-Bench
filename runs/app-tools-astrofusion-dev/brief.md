# How this row was produced

No language model. A local HTTP server in the AstroFusion private repository answers each benchmark item by calling the app's own MCP kundali tools (birth chart, divisional charts, dasha at a moment, dignities, combustion, graha drishti, yogas by name, lordship mapping) which run on the app's Rust engines over Swiss Ephemeris, and the `cite_rule` tool, which looks up the open canon by rule key. The benchmark called it through the generic `http_json` solver in `--input-mode birth` on the full dev split. Conventions (ayanamsa, node, house) were passed from each item. The task-to-tool mapping and the task-to-citation-key table are the operator's and are documented in the private repository; the server never reads item ids, gold, or `input.query`. Engine commit of the oracle: see the result file; the app's Rust core and the oracle agreed on all 955 items after the 2026-11-09 moolatrikona correction (see CORRECTIONS.md).
